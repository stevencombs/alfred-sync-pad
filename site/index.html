How it works

Copy, save, then open it over there.

Give Google Drive a moment to finish sync-pad.json before you look on the other Mac.

  1. 1

    Copy some text

    Copy on this Mac the way you already do. Open Alfred and type pad. Saved snippets are first. Clipboard rows follow the Clipboard divider.

  2. 2

    Save it

    Highlight a clipboard row and press ⌘Return. Sync Pad writes that text into sync-pad.json, next to your Alfred preferences.

  3. 3

    Take it on the other Mac

    Type pad, highlight the snippet, and press Return. Paste with ⌘V. The clip is now in that Mac’s Clipboard History.

Where the text lives

  • Shared snippets are plain text in sync-pad.json, beside Alfred.alfredpreferences, in the folder Alfred already syncs.
  • The GitHub repository holds the workflow. Your clips stay out of git.
  • Each Mac’s Clipboard History stays on that Mac until you press Return on a shared snippet.
  • There is no account and no analytics. The file syncs only because your Alfred folder syncs.

Install

Double-click, then type pad.

Recommended

Alfred package

Download Sync.Pad.alfredworkflow and double-click it. Alfred asks to import the workflow. If that bundle ID is already installed, replace it.

Requirements

What you need

  • Alfred 5 with the Powerpack
  • /usr/bin/python3 (the Xcode Command Line Tools provide it)
  • To share between Macs: Alfred preferences syncing through one folder, such as Google Drive
  • A single Mac can still use pad as a saved-snippet list

Updates

The same path you used to install.

Sync Pad has no updater inside Alfred, and it is not in the Alfred Gallery. The file on main is the current version. Alfred Preferences → Workflows → Sync Pad shows the version you have. This page shows 1.0.

  1. 1

    Shared Alfred preferences

    The workflow lives in the preferences folder your Macs already sync. When a new copy is installed into that folder, Google Drive brings info.plist, sync_pad.py, and icon.png to the other Macs. Wait until Drive finishes, then type pad. If the old behavior is still there, quit Alfred and open it again.

  2. 2

    You double-clicked the package

    Download Sync.Pad.alfredworkflow again and double-click it. Alfred matches bundle ID com.retrocombs.syncpad and replaces the workflow you have.

  3. 3

    You cloned the repo

    Run git pull, then ./scripts/install.sh. That copies the workflow into Alfred and reloads it. Run ./scripts/package.sh when you also want the downloadable zip rebuilt.

What an update leaves alone

  • sync-pad.json sits beside the preferences folder, outside the workflow. Replacing Sync Pad leaves your saved snippets in place.
  • Clipboard History is Alfred’s database. An update does not clear it.
  • The keyword stays pad and the bundle ID stays com.retrocombs.syncpad, so the new package replaces this workflow.
  • Let Drive finish before you edit the workflow on a second Mac. The last saved copy of those files is the one Drive keeps.

FAQ

Questions, answered.

How do I get a new version?

There is no automatic update. Macs that share Alfred’s preferences folder pick up the new workflow files when Google Drive finishes syncing that folder. Everyone else downloads Sync.Pad.alfredworkflow again and double-clicks it, or runs git pull and ./scripts/install.sh. The Updates section has the three paths.

Will an update erase saved snippets?

No. Saved snippets live in sync-pad.json, next to Alfred.alfredpreferences. The workflow package is only info.plist, sync_pad.py, and icon.png.

Is the shared text private?

It is plain text in the folder Alfred syncs, which on this setup is Google Drive. Share only text you are willing to keep there. The GitHub repository does not contain sync-pad.json.

Does Return paste into the front app?

Return copies. Click the document and press ⌘V. The snippet also becomes the newest item in Alfred Clipboard History on that Mac.

Can I share an image or a file?

Sync Pad shares text. Images and files stay on the Mac where you copied them.

What does it cost?

Nothing. Sync Pad is free. If it saves you from mailing a snippet to yourself, a tip is welcome.
